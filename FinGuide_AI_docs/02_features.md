# Features Specification

## 1. Income Tracker
### Input
- Monthly income
- Currency

### Output
- Total monthly income
- Income history

## 2. Expense Tracker
### Categories
- Food
- Transport
- Education
- Entertainment
- Shopping / Other

### Output
- Total expenses
- Remaining money
- Category percentages
- Spending trends

### Example AI insight
"Bu oy daromadingizning katta qismi oziq-ovqat xarajatlariga ketgan. Xarajatlarni rejalashtirish uchun haftalik limit belgilashni ko‘rib chiqishingiz mumkin."

## 3. Savings Goal
### Input
- Goal name
- Target amount
- Current savings
- Monthly contribution

### Formula
Remaining = Target Amount - Current Savings

Estimated Months = Remaining / Monthly Contribution

Natija butun oyga yuqoriga yaxlitlanadi.

## 4. Credit Simulator
### Input
- Principal
- Annual interest rate
- Term in months

### Output
- Estimated monthly payment
- Total repayment
- Total interest
- Basic risk explanation

AI hisob-kitobni bajarmaydi; hisoblangan natijalarni tushuntiradi.

## 5. AI Financial Advisor
### Example question
"Menda $300 bor. Telefon olganim yaxshimi yoki jamg‘arganim?"

### AI context
- Monthly income
- Monthly expenses
- Current savings
- Savings goals
- Credit obligations
- User question

### Expected response structure
1. Short conclusion
2. Option A
3. Option B
4. Risks
5. Recommended next step

AI qat’iy "shuni qiling" demasdan, qarorning sabablarini tushuntirishi kerak.
