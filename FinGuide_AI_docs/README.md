# FinGuide AI — Project Documentation

FinGuide AI — yoshlarning daromad, xarajat, jamg‘arma va kredit qarorlarini tushunishga yordam beruvchi AI-powered moliyaviy yordamchi.

## Maqsad
Foydalanuvchi o‘zining moliyaviy ma’lumotlarini kiritadi, tizim esa hisob-kitoblarni amalga oshirib, AI orqali tushunarli tavsiyalar va variantlar taqqoslovini beradi.

## MVP funksiyalar
1. Income Tracker
2. Expense Tracker
3. Savings Goal
4. Credit Simulator
5. AI Financial Advisor

## Asosiy prinsip
AI foydalanuvchining o‘rniga moliyaviy qaror qabul qilmaydi. U ma’lumotlarni tahlil qiladi, variantlarni solishtiradi, xavf va afzalliklarni tushuntiradi.

## Tavsiya etiladigan MVP stack
- Frontend: React / Next.js
- Backend: Node.js
- Database: PostgreSQL yoki Supabase
- AI: Claude API
- Authentication: Supabase Auth yoki Firebase Auth
- Deployment: Vercel + Supabase

## Muhim
Kredit va boshqa moliyaviy hisob-kitoblar AI'ga topshirilmasdan, backenddagi aniq formulalar orqali hisoblanadi. AI esa natijani tushuntirish va tahlil qilish uchun ishlatiladi.
